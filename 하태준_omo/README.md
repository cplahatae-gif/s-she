# SAFEPLAY 마지막 자물쇠

레미콘 공장의 이물질 제거 작업을 다루는 독립 구현입니다. 공용 이미지와 Phaser(브라우저 2D 게임 엔진)를 상대 경로로 읽으므로 저장소 전체를 유지하세요.

저장소 루트에서 정적 서버를 실행합니다.

```powershell
py -3 -m http.server 8770 --bind 127.0.0.1
```

접속 주소: http://127.0.0.1:8770/하태준_omo/

공장 구역은 마우스로 클릭하거나 Tab으로 선택한 뒤 Enter 또는 Space로 진입합니다. 상단에서 움직임 줄이기를 설정할 수 있습니다. 이미지 로딩 실패 시 다시 불러오기를 누르세요.

브라우저 검사는 Playwright(브라우저 자동 검사 도구)의 `browser_run_code_unsafe`에 저장소 루트 기준 `filename: "하태준_omo/tests/browser/overview.js"`를 전달합니다. OV01부터 OV04까지 클릭, 키보드, 로딩 실패와 반복 재시도를 검사합니다. 증거는 `.omo/evidence/task-2-*`에 저장됩니다.

현재 셸은 공장 선택과 현장 준비 안내까지 구현합니다. 현장 조작은 후속 통합 대상입니다. 화면 속 차단 지점과 안전조치는 게임용 예시입니다. 실제 작업에서는 승인된 현장별 설비 절차를 따릅니다.
