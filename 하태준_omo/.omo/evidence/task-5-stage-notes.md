# 작업 5 현장 모듈 구현 기록

- 구현 범위: `src/site/stage.js`와 이 기록만 생성했다. 앱, 스타일, 진단, 브라우저 검사는 주 실행자가 소유한다.
- 근거: 구현계획 작업 4, 5, 7과 `docs/contract.md`, 로컬 배치 및 규칙 모듈을 읽었다.
- 검사: `node --check 하태준_omo/src/site/stage.js` 통과. 실제 브라우저 검증은 주 실행자가 진행한다.

## 공개 인터페이스

`mountStage(root, { onInspect, onFrame, reducedMotion })`는 Phaser(브라우저 2D 게임 엔진) 장면 생성 후 제어 객체를 반환한다. 기존 HTML의 로컬 엔진 파일을 사용하며 이미지 자산은 읽지 않는다. 엔진 누락과 15초 로딩 시간 초과는 오류로 반환하고 생성 중인 자원을 정리한다.

- `snapshot()`은 복사본을 반환한다. 시작 x는 600, 초기 정지는 참, 방향은 1이다. 도형 단계의 보행 프레임은 0, 발바닥 좌표는 null이다.
- `setPaused()`는 매번 입력과 속도를 초기화한다.
- `setPosition()`은 x, 선택적인 방향과 카메라 위치를 검증 후 복원한다. 이동 범위와 카메라 범위를 제한한다.
- `reset()`은 사고 효과, 위치, 방향, 카메라, 표시용 안전 상태와 입력을 초기화하고 정지한다.
- `updateSafety()`는 전달값을 복사해 자물쇠와 표지만 그린다. 규칙 상태는 변경하지 않는다.
- `setReducedMotion()`, `focus()`, `clearAccident()`, `destroy()`를 제공한다.
- `playAccident()`는 중복 호출에 같은 약속 객체(Promise)를 반환한다. 일반 1,100밀리초, 움직임 줄이기 750밀리초에 참으로 완료한다. 취소는 타이머를 제거하고 거짓으로 완료한다. 완료한 연출도 초기화 전까지 동일 약속 객체를 유지한다.

## 입력과 표시

캔버스 또는 조사 버튼의 방향키와 A/D로 이동하고 E로 조사한다. 반복 E, 정지, 숨김, 영역 밖 포커스는 조사와 이동을 차단한다. 키 해제, 창 비활성화, 문서 가시성 변경, 포커스 이동, 정지, 초기화에서 입력을 정리한다. 반대 방향 동시 입력은 중립이다.

즉시 속도 270과 즉시 카메라 추적은 기능 게이트용이다. 가속과 카메라 보간은 후속 작업에서 교체한다. 회색 산업 구조, 황색 난간, 네 대상 명칭, 작업자 도형과 임시 화면 안내만 그린다. 사고 외에는 벨트가 움직이지 않는다. 발바닥과 자산 품질은 측정하거나 합격 처리하지 않았다.

부모 스타일은 `.stage-canvas-host`의 크기와 16:9 화면, `.field-controls`의 하단 위치, 루트의 상대 위치를 맡는다. `.accident-layer`는 루트 내부를 덮는다. 진단은 매 렌더링 프레임의 `onFrame(snapshot)`을 통해 앱이 소유한다.

생략한 검사: 실제 브라우저와 자산 기반 시각 검사. 위험: 앱 및 스타일 통합 후 크기, 입력, 사고 시간을 실제 브라우저에서 확인해야 한다.
