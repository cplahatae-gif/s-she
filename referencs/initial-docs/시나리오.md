# 시나리오 v3: 「마지막 자물쇠」 (작업자 시점 초안)

**확인된 방향:** 레미콘 공장 컨베이어의 이물질 제거 작업자가 주인공이다. 작업자가 잠금·표지·차단 확인(LOTOTO, Lock Out·Tag Out·Try Out)을 하러 가는 과정을 체험한다. 차단이 불완전한 상태로 작업에 들어가면 사고 재현과 되감기로 이어진다.

**상태:** 역할과 작업 내용은 사용자 확인 완료. 아래 장면·대사·상태 설계는 구현을 위한 제안이다. 현장별 차단 지점과 확인 방법은 사내 설비 절차 및 교육자료 대조 후 확정한다. 기존 운전원용 함수 계약은 아직 변경하지 않았다.

## 1. 한 장 요약

| 항목 | 내용 |
|---|---|
| 장소 | 레미콘 공장의 벨트 컨베이어(B/C) 라인 |
| 플레이어 | 컨베이어 점검구 안 이물질을 제거할 작업자. 본인의 자물쇠를 체결하는 사람 |
| 시작 상황 | 컨베이어가 멈춰 있고 이물질 제거 요청을 받았다. 작업자는 점검구 밖 안전한 위치에 있다 |
| 표면 목표 | 이물질을 제거하고 작업을 끝낸다 |
| 교육 목표 | 멈춰 있다는 이유만으로 들어가지 않고, 작업 전에 에너지 차단·본인 잠금·표지·차단 확인을 완료한다 |
| 핵심 행동 | 작업 대상 확인 → 차단 지점까지 이동 → 에너지 차단 → 본인 자물쇠·표지 체결 → 잔류 에너지 안전조치와 차단 확인 → 점검구로 이동 → 작업 진입 판단 |
| 성공 | 필요한 안전조치를 완료한 뒤 이물질 제거 작업에 들어간다 |
| 실패 | 불완전한 차단 상태로 작업에 들어가 컨베이어가 불시에 움직인다. 암전·카드·되감기 |
| 한 판 범위 | 작업 전 안전 확보부터 안전한 이물질 제거까지. 작업 후 재가동은 이번 핵심 흐름에 포함하지 않는다 |
| 첫 화면 | 기존 전체 공장뷰에서 B/C 구역 선택. 시나리오는 하나 |

자물쇠를 체결하는 장면만으로 성공 처리하지 않는다. 정지 버튼과 실제 에너지 차단은 다르며, 잠금 후에도 차단이 유효한지 확인해야 한다. 작업자는 해당 설비의 차단 절차를 수행하도록 교육받고 권한을 부여받은 사람으로 설정한다.

## 2. 장면 흐름

| 장면 | 화면과 상황 | 플레이어 행동 | 다음 장면 |
|---|---|---|---|
| 공장 전경 | 전체 공장뷰, B/C 구역 표시 | 구역 선택 | 작업 요청 |
| 작업 요청 | 점검구 밖에 작업자 등장. 컨베이어는 멈춰 있다. 이물질 제거 요청 표시 | 작업 대상 확인 | 현장 탐색 |
| 현장 탐색 | 점검구, 조작반, 에너지 차단·잠금 지점이 서로 떨어져 있다 | 좌우 이동과 가까운 대상 상호작용 | 차단·잠금 또는 작업 진입 판단 |
| 차단·잠금 | 해당 컨베이어의 차단 장치와 잠금 위치 확대 | 실제 에너지 차단, 본인 자물쇠 체결, 본인 표지 부착 | 차단 확인 |
| 차단 확인 | 잠금 상태, 잔류 에너지 안전조치, 차단 확인 상태 표시 | 현장 절차에 따른 안전조치 및 차단 확인 | 점검구로 이동 |
| 작업 진입 판단 | 점검구 앞, 완료한 조치와 빠진 조치 표시 | 안전조치 보완 또는 작업 진입 선택 | 탐색 / 사고 재현 / 안전한 작업 |
| 사고 재현 | 불완전한 차단 상태에서 작업 진입 후 컨베이어가 움직임 | 사고 카드에서 되감기 | 작업 진입 전으로 복귀 |
| 안전한 작업 | 모든 필수 조치를 완료하고 이물질 제거 | 결과 확인 | 결과 |
| 결과 | 완료한 조치, 판단 시도, 되감기 횟수, 고정 설명과 AI 보충 설명 | 다시 연습 / 공장으로 | 초기화 / 공장 전경 |

이동 자체가 체험의 일부다. 멀리서 메뉴만 눌러 잠금이 완료되지 않도록, 차단·잠금 지점에 가까이 가야 행동할 수 있게 한다. 시작 위치에서 이미 점검구 안에 들어가 있거나, 잠금이 완료돼 있지 않다.

## 3. 현장 배치와 상호작용

| 대상 | 역할 | 상호작용 |
|---|---|---|
| 점검구 | 이물질 제거 장소. 시작 위치는 그 바깥 안전한 구역 | 작업 대상 조사, 작업 진입 판단 |
| 조작반 | 설비가 정지 중임을 보여 주는 맥락 | 정지 상태 확인. 정지 버튼 조작만으로 에너지 차단 완료 처리하지 않음 |
| 에너지 차단·잠금 지점 | 실제로 해당 설비의 에너지를 차단하고 잠그는 곳 | 대상 확인, 차단, 개인 자물쇠·표지 체결 |
| 차단 확인 지점 | 현장 절차에 따라 차단의 유효성을 확인하는 곳 | 확인 행동과 결과 표시 |

배치 수치와 차단 확인 위치는 현장 담당자가 정한다. 기존 조작반·잠금장치·점검구 소재는 활용할 수 있으나, 점검구 안 동료를 찾는 장면은 주인공의 작업 진입 지점으로 바뀐다.

## 4. 행동과 화면 문구 초안

### 작업 요청

컨베이어 점검구 안에 이물질이 끼었습니다. 제거 작업을 맡았습니다. 벨트는 멈춰 있지만, 작업에 들어가기 전에 직접 안전을 확보해야 합니다.

### 조작반 조사

벨트는 멈춰 있습니다. 하지만 정지 표시만으로 에너지 차단을 확인할 수는 없습니다. 해당 컨베이어의 차단 지점으로 이동하세요.

### 차단·잠금 지점

내가 작업할 컨베이어의 차단 지점인지 확인하세요. 현장 절차에 따라 에너지를 차단하고, 본인 자물쇠와 표지를 체결하세요. 열쇠는 본인이 관리합니다.

행동은 화면에서 구분한다: 에너지 차단, 본인 자물쇠 체결, 표지 부착. 자물쇠가 화면에 보이는 것과 실제 차단 장치를 잠근 상태를 구분한다.

### 차단 확인

잠금 후에도 확인이 필요합니다. 현장 절차에 따라 잔류 에너지를 안전하게 처리하고 차단이 유효한지 확인하세요. 확인되지 않은 상태에서는 작업에 들어가지 않습니다.

차단 확인은 설명창을 읽는 것만으로 완료되지 않는다. 플레이어가 확인 행동을 수행하고, 화면에 그 결과를 보여 준다. 기동 시도 등 구체적인 방법은 설비 절차에 맞춰 확정하며, 단순히 벨트가 움직이지 않았다는 이유만으로 모든 에너지가 안전하다고 판정하지 않는다.

### 작업 진입 판단

- 빠진 안전조치를 확인하고 보완한다.
- 현재 상태로 점검구에 들어가 이물질을 제거한다.

안전조치 보완을 고르면 현장으로 돌아간다. 작업 진입은 아래 상태 판정에 따라 안전한 작업 또는 사고 재현으로 이어진다.

## 5. 성공·실패 판정 설계

**조사 기록과 안전조치 완료 상태는 다르다.** 잠금 지점을 조사했다고 자물쇠 체결이 완료되지 않으며, 차단 확인 설명을 읽었다고 확인이 완료되지 않는다.

작업 진입에 필요한 상태:

- 작업 대상에 맞는 에너지가 실제로 차단됨.
- 차단 장치에 본인 자물쇠가 제대로 체결됨.
- 본인 표지가 부착됨.
- 필요한 잔류 에너지 안전조치가 완료됨.
- 차단이 유효함을 현장 절차에 따라 확인함.

| 진입 시 상태 | 결과 | 고정 설명 초안 |
|---|---|---|
| 모든 필수 조치 완료 | 성공, 안전한 이물질 제거 | 멈춰 있다는 표시를 믿고 들어가지 않았습니다. 직접 차단하고 본인 자물쇠·표지를 체결한 뒤, 차단을 확인하고 작업에 들어갔습니다. |
| 정지 상태만 확인하고 실제 차단·잠금 생략 | 사고 재현 | 벨트가 멈춰 있어도 다시 움직일 수 있습니다. 정지 표시는 에너지 차단과 잠금의 확인을 대신하지 못합니다. |
| 자물쇠를 달았으나 실제 차단 장치를 잠그지 못함 | 사고 재현 | 자물쇠가 보이는 것만으로 안전해지지 않습니다. 해당 설비의 에너지를 차단하고 그 차단 상태를 유지하도록 잠가야 합니다. |
| 불완전한 차단을 확인하지 않고 진입 | 사고 재현 | 잠금 뒤 차단 확인을 생략해 불완전한 차단을 발견하지 못했습니다. 작업 전에 차단의 유효성을 확인해야 합니다. |
| 표지 또는 확인 등 필수 단계 누락, 위험한 에너지 상태는 설정되지 않음 | 미완료 안내, 안전조치 보완 | 아직 필수 조치가 끝나지 않았습니다. 빠진 단계를 완료한 뒤 작업에 들어가세요. |
| 차단 확인에서 이상 발견 | 진입 보류, 안전조치 보완 | 차단이 확인되지 않았습니다. 현장 절차에 따라 원인을 확인하고 안전조치를 보완하세요. |

표지를 빠뜨렸거나 확인을 생략했다는 이유만으로 벨트가 반드시 움직인다고 묘사하지 않는다. 사고 분기는 실제 차단 실패 또는 잠금 실패로 위험한 에너지가 남아 있는 상태와 연결한다. 차단 실패의 구체적인 원인과 화면 표현은 현장 절차 확인 후 확정한다. 무작위 사고는 넣지 않는다.

## 6. 사고 재현과 되감기

사고는 잠금장치 앞에서 발생하지 않는다. 불완전한 차단 상태로 점검구에 들어가 작업하려 할 때 발생한다.

기존 연출을 활용한다: 붉은 점멸 → 벨트 움직임 또는 화면 흔들림 → 암전 → 사고 카드 → 되감기. 부상 장면·피·피해자 실명은 넣지 않는다. 움직임 줄이기 설정에서는 붉은 고정 레이어 → 암전 → 카드로 완주한다.

사고 카드 초안:

**벨트가 움직였습니다.**

이물질을 제거하려던 순간 컨베이어가 불시에 움직였습니다.

선택한 경로에서 빠뜨리거나 잘못 수행한 조치를 고정 설명으로 보여 줍니다.

**되감기**

현실에는 없는 버튼입니다.

되감기는 작업 진입 전 안전한 위치로 돌아간다. 조사 기록·판단 시도는 유지하고 되감기 횟수만 늘린다. 안전조치는 사고 전 상태를 유지하며, 잘못된 차단·잠금을 보완할 수 있어야 한다. 되감기로 안전조치가 자동 완료되지 않는다.

## 7. 결과와 교육 연결

성공 제목 초안: **안전을 확인하고 작업에 들어갔습니다.**

- 기록: 완료한 안전조치, 판단 시도 횟수, 되감기 횟수.
- 교육 연결: 정지와 에너지 차단은 다릅니다.
- 교육 연결: 본인 자물쇠와 표지로 본인의 작업을 보호합니다.
- 교육 연결: 잠금 후에도 차단이 유효한지 확인하고 작업에 들어갑니다.
- 마지막 문장: 현실에는 되감기가 없습니다.
- 버튼: 다시 연습 / 공장으로.

AI(인공지능)는 코드가 결정한 결과에 보충 설명만 제공한다. 실패 시 고정 설명과 "기본 설명 사용"을 유지한다. 무전 압박은 필수 흐름에서 제외하고, 추가 여부는 별도로 정한다.

## 8. 구현 전 계약 변경 제안

이 절은 변경 의도를 전달하기 위한 제안이다. `docs/contract.md`와 `AGENTS.md`의 기존 규칙을 이미 수정한 것으로 간주하지 않는다.

| 기존 계약 | 필요한 변경 |
|---|---|
| 운전원, 오른쪽 조작반 앞 시작 | 이물질 제거 작업자, 점검구 밖 안전한 위치 시작 |
| 점검구 안 동료 조사 | 플레이어가 진입할 작업 장소 조사 |
| 조사 2곳 완료로 성공 | 조사 기록과 별개로 실제 차단·개인 잠금·표지·잔류 에너지 조치·확인 상태 판정 |
| 남의 자물쇠 제거 / 방송 후 재가동 / 재가동 보류 선택 | 현재 안전조치 상태에서 작업 진입 / 안전조치 보완 선택 |
| 재가동 판단 후 사고 | 불완전한 차단 상태로 작업에 진입한 뒤 사고 |
| 조사 기록 중심 한 판 상태 | 실제 안전조치 상태도 한 판에 보관. 공장 복귀 때 유지, 다시 연습 때 전부 초기화 |
| 기존 AI 요청과 서버 재판정 | 새 행동·안전조치 상태를 허용 목록과 자료형으로 검증하고 서버도 동일한 근거로 재판정 |

기존 `control`, `lock`, `worker`, `remove`, `notify`, `hold`, `start` 식별자를 새 의미로 조용히 재사용하지 않는다. 새 식별자·함수 형태는 담당자 간 합의 후 제공 함수·호출부·검사를 함께 반영한다.

하태준 담당에 전달할 내용: 주인공·시작 위치 및 판정 규칙 변경, 안전조치 상태의 `src/app.js` 소유, 현장·패널 행동 콜백 추가, AI 요청과 서버 검증 변경. 해당 파일은 이번 원고 변경에서 수정하지 않는다.

권기봉 담당 구현 범위: `src/site/`, `src/scenario/`, `src/ui/`, `tests/`. 차단 지점에서만 행동 가능, 미완료 진입, 실제 차단 실패 사고, 성공, 잘못된 행동 식별자, 되감기 후 기록·안전조치 유지, 다시 연습 초기화를 검사한다.

## 9. 안전 근거와 남은 확인

기존 사내 자료: 2022-12-08 EHS지원팀 LOTOTO 교육자료, 2026-01-14 사내 안전강사 강의. 원문은 저장소 밖에 있어 이번 변경에서 직접 대조하지 못했다. 기존 문서의 사고 통계·사례는 새 화면 문구에 자동으로 옮기지 않는다.

일반 원칙 확인 자료: [OSHA 에너지 관리 절차](https://www.osha.gov/etools/lockout-tagout/tutorial/application-energy-control), [OSHA 제어회로와 잔류 에너지 안내](https://www.osha.gov/etools/lockout-tagout/hot-topics/energy-control-program/energy-control-circuitry-prohibition). OSHA는 미국 산업안전보건청이며, 이 자료는 정지와 차단의 구분, 잠금·표지, 잔류 에너지 조치 및 작업 전 차단 확인의 일반 원칙을 확인하는 참고자료다. 국내 현장 절차의 승인 근거로 사용하지 않는다.

구현 전 확인할 것: 해당 컨베이어의 실제 차단 대상과 잠금 위치, 잔류 에너지 안전조치, 작업자의 권한, 차단 확인 방법, 체결 실패의 구체적인 표현. 원고의 세부 대사와 배치는 이 확인 결과에 맞춰 확정한다.
