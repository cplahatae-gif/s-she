# 오답 장면·짧은 설명 명세

사용자 화면에서 타인 잠금 선택은 긴 문장과 같은 정적 자세로 보였다. 오답은 선택의 후속 상황을 먼저 보여주고, 오른쪽에는 제목과 ‘잘못된 점 / 위험 / 다음 행동’ 세 줄만 우선 표시한다. 기존 강철·흑연 바탕과 안전 황색을 유지하며 제목 24px·본문 16px로 읽기 쉽게 한다. 동일 카드 세 개를 쌓지 않고 한 안내판의 세 행으로 구성한다. 원래의 상세한 설명은 닫힌 네이티브 ‘자세한 설명’ 안에 둔다.

18개 오답의 문구는 `choice-feedback.mjs`에서 고유한 선택 ID별로 제공한다. 정답·게임 판정·시나리오 원문·학습 근거는 변경하지 않는다. 표지 누락 자체가 기동을 일으키지 않으며, 시험 중 이상은 진입 전에 보류한다. 타인 잠금은 그 작업자가 잠금을 해제하는 경우 본인의 보호가 사라질 수 있다는 예시로 표현하며 필연적인 사고라고 단정하지 않는다.

오답·사고 결과의 ‘장면 다시 보기’는 현재 pending 결과를 가져와 같은 장면만 재생한다. 새 선택을 판정하거나 학습 이벤트·선택 횟수·되감기 횟수·단계 번호를 바꾸지 않는다. 원래 선택 전 위치와 안전조치를 사용하고, 사고 상태를 정리한 뒤 재생한다. 전경 이동·장면 파괴는 기존 세대 번호의 취소 계약으로 오래된 결과를 막는다. 정답·완료 학습 회고와 교육 연결은 보존한다.

검사는 18개 유효 오답의 빠짐없는 짧고 고유한 설명, 정답·알 수 없는 ID에 대한 거부, 판정·안전조치 불변 경계를 확인한다. 실제 장면과 재생 횟수 불변은 주 담당자의 브라우저 QA로 검증하고 `qa/wrong-choice`에 기록한다. 새 모듈은 정적 서버 허용 목록에만 추가한다. 커밋·푸시·패키지 설치는 하지 않는다.
