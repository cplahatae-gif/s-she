# 종료 결과·학습 코칭 화면 명세

이번 변경은 게임 종료 결과를 화면 중앙의 큰 회고 화면으로 바꾸고, 실제 선택 기록에서 보완할 절차와 후속 교육을 연결한다. 짧은 단계 결과·사고 설명은 현장을 볼 수 있는 옆 패널을 유지한다. 기존 6단계 판정은 변경하지 않는다.

## 화면 설계

기존 강철·흑연·안전 황색 토큰과 한국어 로컬 글꼴을 유지한다. 종료 화면은 16:9 장면 중앙에 폭 최대 1060px, 장면 너비보다 64px 작게 표시하며 높이는 장면보다 80px 작게 제한한다. 제목과 선택·되감기·첫 시도·보완 단계 지표 뒤에 여섯 완료 확인을 둔다. 본문은 왼쪽 선택 기록·학습 행동, 오른쪽 우선 교육의 두 열로 구성한다. 교육 목록을 대시보드의 동일 카드 더미로 만들지 않는다. 긴 본문만 스크롤하고 다시 연습·공장 전경·교육 연계 데이터 저장 버튼은 하단에 남긴다. 큰 글씨와 작은 화면에서도 내부 스크롤을 허용한다.

학습 기록은 선택이 실제 수락될 때만 `{optionId}`를 하나씩 추가한다. 되감기·공장 왕복은 기록을 유지하고 새 연습은 모두 초기화한다. 상한 256건에서 추가 선택을 차단하고 새 실습 버튼을 안내하며 조용히 자르지 않는다.

## 모듈 연결

`learning.mjs`의 `CATALOG`, `MAX_LEARNING_EVENTS`, `buildLearningReport`, `getLearningReport`, `exportLearningRecord`를 사용한다. 완료 시 규칙 기반 분석을 즉시 표시하고 서버 분석을 별도 AbortController·세대 번호로 요청한다. 키 없는 서버·정적 서버·오류에서는 ‘선택 기록 분석 (기본)’을 표시한다. 실제 AI 응답을 받은 경우에만 AI 코칭으로 표시한다. AI는 성공 판정·횟수·선택 근거·교육 ID를 변경하지 않는다. 다시 연습·전경 이동·교육 화면 전환은 오래된 요청이 새 화면을 덮지 못하게 취소한다.

분석은 실제 선택 근거, 보완한 단계, 첫 시도에 완료한 단계와 이번 실습에서 관찰된 재선택을 설명한다. 학습 의지·성격·동기를 추정하지 않는다. 추천 교육 버튼은 카탈로그의 짧은 설명과 4지선다 확인 문제를 앱 안에서 연다. 정답·오답에 구체적 이유를 표시하고 기존 분석 화면으로 돌아간다. 교육 문제는 게임의 선택·성적 기록을 변경하지 않는다.

교육 연계 데이터 저장은 익명 선택·지표·교육 ID를 JSON으로 사용자 클릭 때 내려받는다. 외부 LMS 전송이나 실제 등록을 구현했다고 표시하지 않는다. API 키는 서버 환경변수에서만 읽으며 브라우저 파일에 저장하지 않는다. 기존 3문장 보충 설명 흐름을 유지한다.

## 확인 경계

앱 ES 모듈 구문, 완료 뒤 기록 분석·근거·교육·정오답·돌아가기·JSON 내려받기, 요청 취소와 새 연습 초기화, 큰 글씨의 중앙 패널·고정 하단·스크롤을 검사한다. 실제 브라우저 관찰은 주 담당자가 기록하며 새로운 `qa/learning` 보고서는 그 자료를 받은 뒤 작성한다. 커밋·푸시하지 않는다.

## 전경 화면 참고 이미지 반영 · 2026-10-09

사용자의 143930·143945 스크린샷을 확인했다. 전경은 밝은 청회색 바탕 `#e1e7e8`, 짙은 청색 글씨 `#233c49`, 브랜드 청록 `#34778a`, 위치 안내 청록 `#568985`, 이동 가능 황색 `#db9c30`을 사용한다. SP 표시와 ‘세이프 플레이 / 현장을 이해하는 첫걸음’, ‘화성공장 / 공간 탐색’, ‘익숙한 현장, 새로운 시선.’, ‘공장을 돌아보고 작업 구역의 설비를 살펴보세요.’를 실제 문구로 적용한다. 큰 제목은 왼쪽 밝은 안내 영역에 두고 오른쪽에는 기존 사진 전체가 잘리지 않는 지도를 배치한다.

지도는 실제 좌표의 1~5번 핀, 핀과 연결된 큰 장소 이름표, 왼쪽 다섯 장소 안내 목록을 제공한다. B/C만 이동 버튼이고 다른 장소는 ‘위치 안내’다. 활성 B/C는 청록 테두리와 황색 번호·점을 사용한다. 지점 확대·현장 진입·학습 기록 유지·큰 글씨·움직임 줄이기를 보존한다. 실제 3D·회전·다른 작업 구역을 구현한 것처럼 표시하지 않는다. 현장과 종료 회고의 어두운 톤은 그대로 유지한다.

종료 화면의 실제 확인에서 `#dialog-content` 높이 계약이 빠져 본문과 하단 버튼이 패널 밖으로 확장되는 문제를 발견했다. 종료·교육 모드의 컨테이너 높이를 100%로 제한하여 기존 flex 본문이 실제 내부 스크롤이 되고 하단 버튼을 유지하도록 수정한다. 이 수정은 결과 내용·판정·학습 기록에 영향을 주지 않는다.
