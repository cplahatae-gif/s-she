# 세이프 플레이 — 현장을 이해하는 첫걸음

화성공장 공간 탐색 화면은 ‘익숙한 현장, 새로운 시선.’을 시작 문구로 사용합니다. 밝은 청회색 안내 영역과 기존 전체 전경 사진 위의 번호 핀·연결선·큰 이름표로 B/C, 사무동, 치장, 야적장, 사일로를 확인합니다. 이동 가능한 곳은 B/C뿐입니다. B/C를 선택하면 전경이 해당 장소로 확대되고 조작반 근처의 현장에 진입합니다. 작업반장이 “컨베이어 밑에 있는 이물질을 제거하세요.”라고 지시하고, “작업을 시작하기 전에 무엇을 하겠습니까?”라는 질문을 제시합니다.

진행 순서는 **설비 정지 → 오퍼레이터 전달 → MCC 개인 잠금 → 태그아웃 → 트라이아웃 → 이물질 제거**입니다. 단계마다 선택지는 정확히 네 개이며 정답은 하나입니다. 행동을 선택하면 현장 화면에서 그 행동과 상황 변화를 먼저 보여주고 설명 카드를 엽니다. 정답은 ‘다음 단계’로 진행하며, 오답은 선택별 위험을 확인한 뒤 같은 단계에서 다시 선택합니다. 사고가 발생하는 선택에만 사고 재현과 되감기를 적용합니다.

현장은 화면에 맞춘 16:9 게임 화면입니다. 현재 임무만 상단에 표시하고, 네 가지 선택은 하단에서 엽니다. 선택 후에는 질문이 사라져 실제 행동을 보여줍니다. 연락·잠금·표지·시험·제거 및 잘못된 선택의 상황을 재현한 뒤, 짧은 행동 결과는 오른쪽 패널에서 장면을 보며 읽습니다. 오답 안내는 선택별 제목과 ‘잘못된 점 / 위험 / 다음 행동’으로 짧게 표시합니다. 원문은 닫힌 ‘자세한 설명’에서 펼쳐 읽습니다. ‘장면 다시 보기’는 같은 선택의 장면만 재생하며 선택·되감기 횟수와 학습 기록을 추가하지 않습니다. 최종 완료는 화면 중앙의 큰 회고 화면으로 표시합니다. 오답의 ‘다시 선택’과 사고의 ‘되감기’는 선택 전 위치와 안전조치를 복구합니다. 디자인과 연출 계약은 `DESIGN.md`에 있습니다. 이번 오답 후속 장면·짧은 안내·재생 확인은 `qa/wrong-choice/REPORT.md`, 앞선 현장 몰입과 종료 학습 확인은 각각 `qa/immersion/`, `qa/learning/`에 기록합니다.

현장 절차를 검토하기 위한 교육 초안입니다. 실제 차단 대상, 잔류 에너지 처리, 작업 방법은 승인된 현장 절차를 따릅니다.

저장소 루트에서 실행합니다. 기본 체험은 npm 설치나 API 키가 필요하지 않습니다.

```powershell
python -m http.server 8770 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8770/권기봉/초안/>을 엽니다. Phaser는 저장소의 `vendor/phaser.min.js`를 사용합니다. 현장 배경·작업자 자산은 초안 폴더에 있으며 공장 전경과 반장 역할 이미지는 기존 공용 이미지 경로에서 읽습니다.

- 좌우 방향키 또는 A / D: 이동
- 화면 화살표: 누르고 있는 동안 이동, 짧은 클릭 또는 Enter / Space로 한 걸음 이동
- E 또는 현장 행동 선택 버튼: 현재 단계의 위치에서 네 가지 행동 열기
- 선택 화면의 1–4: 해당 행동 선택
- ‘현장 보기’ 또는 선택 화면의 Escape: 현장으로 돌아가기
- 설명 카드: ‘다음 단계’ 또는 ‘다시 선택’으로 확인 후 진행
- 사고 카드: ‘되감기’로 선택 직전으로 복귀. 이전 단계의 안전조치와 기록 유지
- ‘공장 전경’: 위치·단계·안전조치·선택 결과·횟수를 유지하고, B/C 선택 시 이어가기
- ‘다시 연습’: 위치·단계·안전조치·입력·모달·타이머·횟수·설명 요청 초기화
- ‘움직임 줄이기’: 전경 줌 이동·카메라 효과를 줄이고 행동 자세·설비 상태·결과 설명 유지
- ‘큰 글씨’: 질문·네 보기·결과 설명·현재 임무를 확대. 공장 전경에서 미리 선택할 수 있으며 공장 왕복 후에도 설정 유지
- 현재 임무 아래의 방향 안내: 목적지까지 좌우 이동. 대상에 가까워지면 ‘E로 행동 선택’ 표시

선택적 AI 보충 설명 서버는 Node.js 22 이상에서 실행합니다.

```powershell
node 권기봉/초안/server.mjs
```

<http://127.0.0.1:8780/권기봉/초안/>에서 체험합니다. 완료하면 선택 기록을 자동 분석해 보완할 절차와 우선 교육을 표시합니다. `OPENAI_API_KEY`가 있는 서버에서는 AI 코칭을 요청하며, 키가 없거나 정적 서버인 경우 ‘선택 기록 분석 (기본)’을 사용합니다. URL의 `?ai=on`은 기존 최종 3문장 보충 설명을 추가로 요청하는 옵션입니다. `OPENAI_API_KEY`는 서버 환경변수로만 설정합니다. `OPENAI_MODEL`과 `PORT`도 서버 환경변수로 설정할 수 있습니다. 키가 없거나 요청에 실패하면 고정 설명을 사용합니다. 단계 진행과 판정은 코드 규칙이 결정합니다.

규칙 및 서버 검사는 저장소 루트에서 실행합니다.

```powershell
node 권기봉/초안/tests/scenario.test.mjs
node 권기봉/초안/tests/server.test.mjs
node --test 권기봉/초안/tests/motion.test.mjs
node --test 권기봉/초안/tests/action-plan.test.mjs
node --test 권기봉/초안/tests/learning.test.mjs
node --test 권기봉/초안/tests/choice-feedback.test.mjs
```

초안 변경은 `권기봉/초안` 안에서 진행합니다. 사용자의 명시적인 요청 없이 커밋하거나 푸시하지 않습니다.

완료 화면에서는 실제 선택 근거, 첫 시도에 완료한 단계, 오답 뒤 보완한 단계와 재선택 행동을 확인합니다. 이번 기록으로 학습 의지나 성격을 평가하지 않습니다. 추천 교육의 ‘교육 시작 · 확인 문제’는 앱 안에서 짧은 설명과 네 보기 문제를 엽니다. 정답·오답 설명을 읽고 분석 결과로 돌아갈 수 있으며 교육 문제는 게임 횟수를 바꾸지 않습니다.

‘교육 연계 데이터 저장’은 익명 선택·횟수·추천 교육 ID를 JSON 파일로 내려받습니다. 외부 LMS 등록이나 전송 기능은 연결하지 않았습니다. 공장 왕복과 되감기는 선택 기록을 유지하고, 다시 연습은 분석·교육 문제 기록·선택 이력을 초기화합니다. 한 실습은 선택 256회까지 기록하며, 상한에서는 새 실습을 안내합니다. 브라우저 새로고침은 새 실습으로 시작합니다. 종료 화면은 큰 글씨에서도 본문만 스크롤하고 하단 버튼을 유지합니다. 상세 계약은 `specs/postgame-learning.md`, 새 실제 검증은 `qa/learning/`에 기록합니다.
