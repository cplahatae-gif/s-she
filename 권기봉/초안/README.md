# 마지막 자물쇠 체험 초안

공장 B/C 구역에서 시작해 작업자가 차단 지점까지 이동하고, 에너지 차단·본인 자물쇠·표지·잔류 에너지 조치·차단 확인을 수행하는 체험입니다. 조사와 조치 완료 상태는 구분합니다. 실제 차단 또는 잠금이 실패한 상태에서 작업에 진입하면 사고 재현과 되감기로 이어집니다.

**체험 초안 · 현장 절차 검토 전.** 화면의 차단 위치, 행동, 잔류 에너지 처리와 확인 방법은 체험을 위한 가정입니다. 실제 작업 지침이나 승인된 현장 절차를 대신하지 않습니다. 작업 후 재가동은 이 체험에 포함하지 않습니다.

저장소 루트에서 실행합니다. npm 설치나 API 키는 기본 체험에 필요하지 않습니다.

```powershell
python -m http.server 8770 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8770/권기봉/초안/>을 엽니다. 파일을 직접 열지 마세요. 기존 루트 실행 화면과 공장 전경 원본은 변경하지 않았습니다. Phaser는 저장소의 `vendor/phaser.min.js`를 사용합니다.

서버를 통한 선택적 AI 보충 설명은 다음처럼 실행합니다. Node.js 22 이상을 권장합니다.

```powershell
node 권기봉/초안/server.mjs
```

<http://127.0.0.1:8780/권기봉/초안/>에서 체험할 수 있습니다. URL에 `?ai=on`을 붙이면 AI 보충 설명을 요청합니다. API 키는 서버 환경변수 `OPENAI_API_KEY`로만 설정합니다. 선택적으로 `OPENAI_MODEL`(기본값 `gpt-4.1-mini`)과 `PORT`(기본값 `8780`)를 지정할 수 있습니다. 키를 설정하지 않거나 응답이 실패하면 고정 설명과 ‘기본 설명 사용’을 유지합니다. 판정은 항상 동일한 코드 규칙이 결정합니다.

- 좌우 방향키 또는 A / D: 이동
- 화면의 화살표 버튼: 클릭·탭하거나, 버튼에 포커스한 뒤 Enter / Space로 이동
- 가까운 대상에서 E 또는 조사 버튼: 조사와 행동 패널
- 일반 패널의 Escape: 닫고 현장으로 복귀
- 사고 카드: ‘되감기’로만 복귀. 기록과 안전조치는 유지
- ‘다시 연습’: 기록·위치·입력·안전조치·카운터·AI 요청 초기화
- ‘공장으로’: 기록과 위치 보존
- ‘움직임 줄이기’: 사고 점멸·흔들림 없이 고정 레이어, 암전, 사고 카드

규칙 검사와 서버 검사는 저장소 루트에서 실행합니다.

```powershell
node 권기봉/초안/tests/scenario.test.mjs
node 권기봉/초안/tests/server.test.mjs
```

새 자료와 코드는 이 폴더 안에만 있습니다. 공장 전경 원본과 기존 시나리오 참고 이미지는 상대 경로로 읽으며 원본을 수정하지 않습니다. 현장과 작업자 이미지를 불러오지 못하면 오류와 다시 불러오기 안내를 표시합니다.
