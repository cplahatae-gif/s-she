# 정면 선택 화면·입력 복원 검증

2026-10-09, `권기봉/초안`. 루트가 Chrome에서 직접 조작한 [관찰 데이터](observations.json)와 [자동 검사 출력](test-output.txt)을 근거로 작성했다. **최종 검증 통과**. 대표 화면은 [실제 브라우저 크기의 최종 미리보기](12-final-preview.png)다.

## 여섯 단계의 선택 화면

설비 정지 → 오퍼레이터 연락 → MCC 본인 잠금 → 태그아웃 → 트라이아웃 → 제거의 **모든 선택 화면**을 실제로 열었다. 각 화면에서 정면 작업자, 네 선택지, 현재 단계의 질문을 확인했다. 발의 기준은 `floorY=619.2`로 유지되고, 정면 표시만으로 실제 위치·안전 상태·기록을 바꾸지 않았다.

일반 설정에서는 카메라 확대값 1.16과 미세한 호흡 대기 표현을 적용한다. 1024×576의 큰 글씨·움직임 줄이기 설정에서는 확대값 1, 정지된 대기 표현을 확인했다. 현장의 작업자 위치를 이동시키는 대신 선택 시의 표시를 전환한다.

## 작은 화면과 입력

1024×576 큰 글씨 화면에서는 처음 세 선택지와 내부 스크롤을 보여줬다. 처음 휠 입력 시도는 `scrollTop=0`이었으므로 **휠 스크롤 성공을 주장하지 않는다**. A에서 Tab을 세 번 눌러 D에 초점을 옮긴 뒤 내부 스크롤이 **78.67px**로 이동했다. 네 번째 보기의 위·아래 경계 **446.44~502.44px**가 패널 **80~560px** 안에 들어왔다. 네 보기 모두 키보드로 접근 가능했다. 근거는 `small-fourth-reachable`와 [04-small-fourth-reachable.png](04-small-fourth-reachable.png)다. 이 이미지의 초점 테두리 잔상과 DOM의 실제 D 초점은 구분한다.

선택 화면에서 오른쪽 방향키를 1100ms 눌러도 실제 위치는 **1344**로 유지됐다. Esc로 닫으면 정면 표시가 해제되고 위치 **1344**, 카메라 **704**, 기존 측면 자세로 돌아왔다. 숫자 **3**을 900ms 누르고 있어도 설비 정지 행동은 **한 번** 실행돼 선택 1회·되감기 0회였다.

## 행동·되감기·왕복

- 연락 없이 접근하는 오답에서는 정면 표시를 해제하고 실제 접근·동료 기동·벨트 운전·위험 반응으로 이어졌다. 선택 2회·되감기 0회였으며, 되감기하면 위치 **1154**의 정지한 조작반 체크포인트와 측면 표시를 복원했다. 되감기 후 닫았을 때 카메라는 **720.156**이었다.
- 타인 잠금 오답에서는 김 작업자가 자기 잠금을 해제하는 실제 동작을 보였다. 결과는 잠금 없음·차단 ON·벨트 정지, 선택 4회·되감기 1회였다. 장면을 다시 봐도 기록이 늘지 않았다. 행동 중 정면 표시가 남지 않았다.
- 태그 단계에서 공장 전경으로 나갔다가 B/C에 재진입해도 위치 **2618**, 본인 잠금·차단 OFF, 선택 **5회·되감기 1회**를 유지했다. 이동 화면은 측면이었고, E로 선택 화면을 열면 다시 정면으로 전환했다.

근거는 `notify-wrong-actual-restart`, `rewind-restored-side-checkpoint`, `owner-release-side-after-focus`, `owner-scene-replay-no-extra-choice`, `tag-side-before-map`, `map-resume-side-state`다.

## 완료와 초기화

여섯 정답과 연락·본인 잠금 단계의 오답을 포함한 실습을 끝냈다. 결과는 **선택 8회·되감기 1회·첫 선택 완료 4 / 6·보완 단계 2개**였다. 재생이나 정면 표시를 새 선택으로 기록하지 않았다. [완료 화면](11-completed.png)과 `completed-eight-choices-one-rewind`에 근거가 남았다.

다시 연습하면 시작 설명에서 측면 표시와 **0회·0회**로 초기화됐다. 새 선택 화면은 정면 표시·네 보기·**0회·0회**로 시작했다. `restart-clears-counts-and-focus`, `final-preview-native`와 `12-final-preview.png`에서 확인했다. 최신 브라우저의 경고·오류 로그는 빈 배열이었다.

## 검사와 범위

전체 자동 검사는 **Node 항목 59개 통과**, 시나리오 내부 개별 검사를 포함한 **논리 검사 72개 통과**다. 구성은 시나리오 14, 이동 8, 서버 27, 학습 10, 행동 계획 7, 오답 문구 3, 선택 화면 표현 3개다. ES 모듈 문법 검사와 diff 검사도 통과했다. 새 검사는 정면 표현의 원래 상태 보존, 세계 경계의 카메라 제한, 움직임 줄이기를 확인한다.

이번 작업은 선택 화면의 정면 표현과 복원 동작을 검증했다. 수강생 대상의 감정·몰입 효과 측정, 실제 AI 호출이나 새로운 외부 연동은 수행하지 않았다. 모든 편집은 `권기봉/초안` 안에서 진행했고 커밋·푸시하지 않았다. 이 보고서 작성에서는 다른 파일을 수정하지 않았다.
