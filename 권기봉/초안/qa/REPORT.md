# 초안 QA 기록 — 2026-10-09

브라우저 검증은 주 작업 에이전트가 Chrome에서 수행했다. Python 정적 서버 `127.0.0.1:8770/권기봉/초안/` 및 Node 서버 `127.0.0.1:8780/권기봉/초안/?ai=on`을 사용했다. 아래는 해당 실행 증거를 전달받아 정리한 기록이다.

## 브라우저 확인

| 확인 경로 | 관찰 결과 |
|---|---|
| 기존 공장뷰 → B/C → 작업 안내 → 현장 | 작업자 시점 초안으로 진입 |
| 이동 후 가까운 대상에서 E 조사 | 조사만으로 안전조치 표시가 완료되지 않음 |
| 미조치 작업 진입 | 판단 1회, 사고 재현 후 카드 도달 |
| 사고 카드에서 Escape → 되감기 | Escape로 닫히지 않음, 되감기 횟수 1로 증가 |
| 차단 후 다른 위치에 자물쇠 체결 | 다른 체결 위치 표시, 올바른 잠금 상태는 완료되지 않음 |
| 올바른 잠금·잔류 에너지 조치 후 표지·확인 누락 상태로 진입 | 사고 없이 미완료 안내, 판단 2회 |
| 다섯 필수 조치를 완료하고 진입 | 성공, 판단 3회·되감기 1회, 고정 설명 3문장 |
| 다시 연습 | 다섯 상태 초기화, 횟수 0, 시작 x=704, 캔버스 한 개 |
| 공장으로 → 현장 재진입 | 잠금 상태·위치·횟수 유지 |
| 움직임 줄이기 켠 상태에서 미조치 진입 | 사고 카드까지 진행하고 되감기 가능 |
| 방향키·Space·E·Escape와 마우스 클릭 | 이동·버튼·대상 조사·일반 패널 닫기 확인 |
| 좌우 경계와 카메라 | x=76/3124 경계, 이동에 따른 카메라 이동·경계 확인 |
| Node 서버 `?ai=on`, API 키 미설정 | 다섯 조치 완료 후 성공(판단 1·되감기 0), 실제 요청이 `source:fixed` 및 고정 설명 3문장으로 복귀 |
| Node 서버, Chrome 1280×720 | 현장 16:9 배치 확인, 결과 화면이 가로 넘침 없이 표시됨 |

## 남은 확인과 시각적 한계

연속으로 키를 누른 이동·보행과 창 비활성화 시 키 해제는 소스만 검토했다. CUA의 키 입력이 순간 입력이므로 이 두 동작을 수동 검증 완료로 기록하지 않는다. 모바일 화면·실제 터치 조작·모바일 브라우저는 아직 검증하지 않았다. OpenAI 유료 호출은 수행하지 않았다.

현장 배경은 2172×724, 작업자 시트는 1254×1254(2×2 프레임)의 새 생성 자료다. 작업자 프레임의 측정 높이는 580~594px로 차이가 남아 있고, 생성 이미지의 가장자리·투명 경계 품질도 후속 보정 대상이다. 발 접촉점 메타데이터는 배치에 반영했지만 전체 보행 품질이 확정됐다는 의미는 아니다.

실제 설비의 차단 위치·잔류 에너지 처리·차단 확인 방법과 작업자 권한은 현장 절차 검토 전이다. 이 초안의 상태 전이는 실습 가정이며 승인된 작업 절차를 대신하지 않는다. 기존 루트의 운전원용 `AGENTS.md`·`docs/contract.md`는 독립 초안 범위를 유지하기 위해 변경하지 않았다.
