# 결정사항

팀이 정한 것과 아직 안 정한 것. 구현 전에 읽고, 바뀌면 여기부터 고친다. 기준일: 2026-10-09. 사용자 확인으로 주인공과 작업 내용을 변경했다. 세부 구현은 `docs/시나리오.md` v3 초안을 따른다.

## 2. 아직 안 정한 것

`docs/시나리오.md` v3의 역할과 작업 내용은 사용자 확인을 받았다. 세부 안전 절차·대사·상태 설계는 초안이다. 아래 내용을 현장 자료 및 담당자와 확인한 뒤 확정한다. 기존 v2의 질문 목록은 작업자 시점 변경으로 대체한다.

| 번호 | 질문 | 답 | 정한 시각 |
|---|---|---|---|
| Q1 | 해당 컨베이어의 실제 차단 대상과 잠금 위치 | 현장 자료 확인 필요 | |
| Q2 | 잔류 에너지 안전조치 및 차단 확인 방법 | 현장 자료 확인 필요 | |
| Q3 | 작업자의 차단 절차 수행 권한 | 교육·권한을 부여받은 작업자로 설정하는 초안 | |
| Q4 | 잘못된 체결·불완전한 차단의 구체적 원인과 화면 표현 | 현장 자료 확인 후 확정 | |
| Q5 | 시작 위치·현장 배치·화면 문구 | 시나리오 v3 초안 | |
| Q6 | 새 행동 식별자·안전조치 상태·함수 계약 | 담당자 합의 필요 | |
| Q7 | 무전·작업 후 재가동 등 추가 범위 | 핵심 흐름 완료 후 결정 | |

`AGENTS.md`와 `docs/contract.md`에는 운전원·기존 조사 및 선택 판정이 남아 있다. 담당자에게 v3의 계약 변경 의도를 전달하고 해당 담당자가 반영해야 한다. 이번 변경은 원고와 결정사항에 한정하며, 계약 합의나 구현 완료를 뜻하지 않는다.
