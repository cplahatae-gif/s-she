# SAFEPLAY

현장 안전교육 웹 게임 「마지막 자물쇠」. 전체 공장뷰에서 벨트 컨베이어 구역을 고르면 현장에 들어간다. 플레이어는 재가동 버튼을 쥔 운전원이다. 로컬 스위치에 남의 자물쇠가 걸려 있고, 조작반에서 보이지 않는 점검구 안에 동료가 있다. 조사하고 재가동 여부를 고른다. 자물쇠를 풀고 가동하면 벨트가 움직이고 암전된 뒤 되감기로 돌아온다. 현실에는 되감기가 없다.

시나리오 원고와 교육자료 근거는 `docs/시나리오.md`.

현재는 준비 화면, Phaser, 시나리오 원고, 계약, 그리고 사전 제작 참조본(`reference/`)만 있다. 새 게임(`src/`)은 구현 전이며 `assets/images/`는 비어 있다.

## 실행

- macOS / Linux: `python3 -m http.server 8770 --bind 127.0.0.1`
- Windows: `py -3 -m http.server 8770 --bind 127.0.0.1`
- 브라우저: `http://127.0.0.1:8770/`. 종료: Ctrl+C.

HTML 파일을 더블클릭하는 방식은 모듈과 이미지 로드 때문에 쓰지 않는다. AI 설명을 연결한 뒤에는 `server/`의 실행 방법을 여기에 적고, 비밀 파일을 정적으로 제공하지 않는 서버로 바꾼다.
