# 독립 구현 검증 기록

검증일: 2026-10-09. 대상: 하태준 독립 구현, PC Chromium 브라우저. 공용 코드와 자산은 수정하지 않았다.

## 실행과 재현

저장소 루트에서 `python -m http.server 8000`으로 실행하고 `http://localhost:8000/하태준/`을 연다. 판정 검사는 `node --test 하태준/tests/*.test.mjs`로 재현한다.

정상 경로는 B/C 선택, 작업 안내 닫기, 차단 지점으로 이동, 에너지 차단, 본인 자물쇠 체결, 표지 부착, 확인 지점으로 이동, 잔류 에너지 조치, 차단 확인, 점검구 복귀, 작업 진입이다. Tab과 Enter, 이동 방향키, E 또는 이동 버튼의 키보드 실행으로 조작할 수 있다.

## 확인 결과

- 공개 판정 검사 6개 통과: 조사와 차단의 구분, 사고와 미완료 구분, 되감기 기록 유지, 잘못된 행동 거절, 확인 생략과 선행 조건, 오체결 보완 및 확인 무효화.
- 자바스크립트 모듈 구문 검사 통과.
- 공장 클릭과 키보드 진입, 현장 안내, 이동과 방향 반전, 카메라 및 양쪽 경계 확인. 위치 경계는 76과 3124에서 유지됐다.
- 이동 방향키를 누른 동안 실제 위치 증가와 보행 프레임 변화 확인. 배경과 인물은 분리됐고 인물은 한 명이다.
- 차단 생략 후 진입: 사고 카드 표시, Escape 우회 방지, 되감기 후 판단 시도 1과 되감기 1 유지.
- 잘못된 잠금 후 진입: 움직임 줄이기 설정에서도 사고와 되감기 완료. 올바른 잠금 보완 후 표지·잔류 에너지·확인이 빠진 진입은 사고 없이 미완료.
- 차단 확인 실패 표시, 조치 보완 후 확인 통과와 완료 목록 확인.
- 키보드만으로 다섯 조치와 성공 결과 도달: 판단 시도 1, 되감기 0. 빠른 연속 선택에서 이전 예약 포커스가 다음 선택을 덮어쓰던 문제를 수정하고 재검증했다.
- 공장 복귀 후 위치 2204와 완료 상태 유지. 완료 판도 공장 재진입 후 결과 유지.
- 다시 연습 후 위치 704, 판단 시도 0, 되감기 0, 안전조치 0/5, 미확인으로 초기화.
- 작업자 이미지 요청을 차단해 로딩 오류 재현. 요청 복구 후 다시 불러오기에서 작업 안내와 현장 복구.
- 결과 이미지 요청을 차단해 오류와 재시도 버튼 확인. 재시도 후 이미지 복구, 판단 시도 3과 되감기 1 유지.
- 기준 검토와 명세 검토 완료. 결과의 고정 설명 표기, 기록을 유지하는 이미지 재시도, 도달 불가능한 판정 이유를 수정했다.

## 확인 한계

실제 현장 설비의 차단·잔류 에너지·확인 절차를 인증하지 않았다. 다른 브라우저와 휴대폰, 실제 운영 배포는 검사하지 않았다. 생성 보행 이미지의 장시간 자연스러움은 사용자 시각 검토가 필요하다. 창 비활성화 입력 초기화는 코드 검토와 blur 이벤트 재현으로 확인했으며 운영체제별 창 전환은 별도 확인하지 않았다.
