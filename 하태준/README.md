# SAFEPLAY: 마지막 자물쇠

전체 공장 전경에서 B/C 구역을 선택해 이물질 제거 작업자의 안전조치를 체험하는 독립 구현입니다. Phaser는 저장소의 기존 현장 화면 라이브러리입니다. 공용 코드를 수정하지 않습니다.

저장소 루트에서 정적 서버를 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/하태준/`를 엽니다. 파일을 직접 열면 모듈과 이미지 정보가 로딩되지 않습니다.

- 좌우 방향키 또는 A/D: 이동
- E: 가까운 대상 조사
- Tab, Enter, Space: 메뉴와 행동 선택
- Escape: 일반 조사 패널 닫기. 사고 카드는 되감기로 돌아갑니다.
- 움직임 줄이기: 점멸과 흔들림 없이 사고 재현

점검구 조사, 조작반 정지 확인, 에너지 차단, 개인 잠금, 표지 부착, 잔류 에너지 안전조치, 차단 확인은 서로 다른 행동입니다. 실제 차단 또는 잠금 없이 작업에 진입하면 사고 재현과 되감기로 이어집니다. 표지·잔류 에너지 조치·확인만 누락한 경우에는 미완료 안내를 보여줍니다.

공장 복귀 후에는 위치와 기록이 유지됩니다. 다시 연습하면 모든 기록과 현장 상태가 초기화됩니다. 외부 인공지능(AI) 연결 없이 고정 설명을 사용합니다.

검사:

```sh
node --test 하태준/tests/*.test.mjs
```

실제 차단 위치·잠금 구조·잔류 에너지 조치·확인 방법은 현장 절차 검토 전인 게임용 예시입니다. 이 구현의 도식을 실제 설비의 작업 지시로 사용하지 않습니다. 실제 설비 자료를 반영하는 작업은 포함하지 않았습니다.
