# 작업 티켓: SAFEPLAY 「마지막 자물쇠」

[제품 요구사항 문서](./PRD.md)를 바탕으로 공장 진입부터 이물질 제거까지 한 판을 만든다. 상태: T1~T7 구현 및 검증 완료. 외부 이슈 등록 없이 로컬 문서에서 작업 상태를 관리한다.

각 작업은 화면, 행동 상태, 판정 결과, 검사를 연결하는 수직 작업 단위(Vertical slice)다. 선행 작업이 모두 완료된 티켓부터 시작한다. 모든 구현과 파생 자료는 사용자 지정 하태준 독립 영역에 한정한다. 기존 공용 자산과 라이브러리를 읽어 사용하며, 공용 코드를 변경하지 않는다.

## T1. 공장 전경에서 컨베이어 작업 현장에 들어가기

**만들 동작:** 플레이어가 전체 공장샷에서 컨베이어 구역을 선택하면 현장 첫 화면과 이물질 제거 작업 요청을 보고, 공장 전경으로 돌아갈 수 있다.

**선행 작업:** 없음. 바로 시작 가능.

- [x] 기존 공장 이미지에 맞는 컨베이어 구역을 선택할 수 있다.
- [x] 마우스 클릭과 키보드 선택·실행이 모두 가능하다.
- [x] 작업 안내는 주인공을 이물질 제거 작업자로 설명하고 원고의 작업 요청 문구를 사용한다.
- [x] 현장 시작은 점검구 밖의 안전한 위치이며 잠금은 아직 완료되지 않았다.
- [x] PC 브라우저에서 독립 구현 주소로 실행되며, 공용 이미지와 Phaser가 정상 로딩된다.
- [x] 공장과 현장 왕복 때 화면과 이벤트가 중복되지 않는다.
- [x] 로딩 실패는 안내하며, 무한 로딩 또는 잘못된 완료 화면으로 넘어가지 않는다.
- [x] 브라우저에서 키보드·마우스로 진입과 복귀를 검증한다.

## T2. 작업자를 이동시켜 현장 대상을 조사하기

**만들 동작:** 한국인 작업자가 점검구 밖에서 차단 지점까지 직접 이동한다. 플레이어는 점검구·조작반·차단 지점 가까이에서 조사하고, 조작반 정지와 실제 차단의 차이를 확인한다.

**선행 작업:** T1. 공장 전경에서 컨베이어 작업 현장에 들어가기.

- [x] 같은 40대 작업자의 투명 배경 인물과 보행 이미지를 준비한다.
- [x] 인물이 합쳐지지 않은 이동용 배경을 준비하고 인물을 한 명만 표시한다.
- [x] 방향키와 A/D로 이동하며, E로 가까운 대상과 상호작용한다.
- [x] 실제 이동 거리와 발 접촉을 맞추며 정지·반전·경계에서 보행이 깨지지 않는다.
- [x] 화면보다 넓은 현장에서 카메라가 작업자를 따라가고 월드 밖으로 벗어나지 않는다.
- [x] 멀리 있는 대상은 조작되지 않으며 가까운 대상의 안내가 표시된다.
- [x] 각 조사는 원고의 의미와 문구를 유지하고, 중복 조사는 기록을 중복시키지 않는다.
- [x] 조사만으로 안전조치가 완료되지 않는다.
- [x] 패널과 공장 화면에서 이동을 정지하며, 창 비활성화 때 키와 속도를 초기화한다.
- [x] 키보드로 조사·닫기가 가능하고 포커스가 복원된다.
- [x] 거리 제한·조사 상태를 규칙 검사로, 보행·카메라·가림을 브라우저 조작과 화면 캡처로 검증한다.

## T3. 차단 지점에서 에너지 차단과 본인 잠금·표지를 수행하기

**만들 동작:** 플레이어가 차단 지점의 확대 화면에서 실제 차단, 본인 자물쇠 체결, 표지 부착을 따로 수행한다. 잘못된 위치에 자물쇠를 단 상태와 유효한 잠금 상태가 구분되며 보완할 수 있다.

**선행 작업:** T2. 작업자를 이동시켜 현장 대상을 조사하기.

- [x] 해당 위치에 가까이 있을 때만 차단·잠금 확대 화면을 연다.
- [x] 실제 차단 행동과 본인 잠금 및 표지 행동을 각각 구분한다.
- [x] 조작반 정지 확인을 실제 에너지 차단으로 처리하지 않는다.
- [x] 실제 차단 장치와 잘못된 잠금 위치를 선택하는 결과가 다르다.
- [x] 잘못된 체결을 올바른 개인 잠금으로 완료 표시하지 않는다.
- [x] 잘못된 잠금을 발견한 뒤 올바른 위치에 다시 체결할 수 있다.
- [x] 차단·잠금·표지 상태는 패널을 닫고 다시 열어도 유지된다.
- [x] 차단 상태를 바꾸거나 잠금을 보완하면 기존 차단 확인 결과를 무효화할 수 있는 규칙을 둔다.
- [x] 잘못된 행동 식별자·자료형·현재 불가능한 행동은 상태를 바꾸지 않고 거절한다.
- [x] 규칙 검사와 실제 확대 화면 조작으로 정상·오체결·보완 경로를 확인한다.

## T4. 잔류 에너지 안전조치와 차단 확인을 수행하기

**만들 동작:** 잠금 이후 플레이어가 게임용 예시의 잔류 에너지 안전조치와 차단 확인을 실제로 수행하고 결과를 본다. 확인 실패가 드러나면 작업을 보류하고 보완 후 다시 확인한다.

**선행 작업:** T3. 차단 지점에서 에너지 차단과 본인 잠금·표지를 수행하기.

- [x] 잔류 에너지 조치와 차단 확인은 서로 다른 행동이다.
- [x] 설명창을 읽거나 열기만 해서는 완료되지 않는다.
- [x] 실제 차단 또는 유효한 잠금이 없을 때 확인이 통과하지 않는다.
- [x] 이상 발견은 명확한 결과와 보완 안내로 표시된다.
- [x] 보완 후 다시 확인해 성공 결과를 얻을 수 있다.
- [x] 확인 뒤 차단·잠금·잔류 에너지 상태가 바뀌면 다시 확인해야 한다.
- [x] 완료 목록에 각각의 조치와 확인 결과를 구분해 표시한다.
- [x] 구체적 설비 절차가 미확정인 부분을 임의의 현장 사실로 소개하지 않는다.
- [x] 누락·실패·보완·확인 무효화의 행동 결과를 규칙 검사와 브라우저 조작으로 확인한다.

## T5. 불완전한 차단 상태로 진입해 사고와 되감기를 경험하기

**만들 동작:** 실제 차단이나 잠금이 불완전한 상태로 작업에 들어가면 사고 재현과 선택의 이유를 보고, 기록을 유지한 채 진입 전 안전한 위치로 되감아 조치를 보완한다.

**선행 작업:** T3. 차단 지점에서 에너지 차단과 본인 잠금·표지를 수행하기.

**선행 작업의 이유:** 위험 분기는 실제 차단·잠금 상태로 결정한다. 잔류 에너지 및 확인의 성공 경로가 완성되기 전에도 정지 상태만 믿은 진입과 오체결 진입은 시연할 수 있다.

- [x] 점검구에서 안전조치 보완 또는 현재 상태로 진입을 선택한다.
- [x] 차단 생략과 잘못된 잠금이 있는 진입은 무작위 요소 없이 사고로 판정된다.
- [x] 사고는 작업에 진입한 뒤 발생하며 부상·피·실명을 넣지 않는다.
- [x] 붉은 연출, 짧은 흔들림 또는 벨트 움직임, 암전, 사고 카드 순서로 6초 이내에 완료된다.
- [x] 원고의 사고 카드와 실패 경로에 맞는 고정 이유를 제공한다.
- [x] 연출 중 반복 입력으로 카드·판정·판단 시도가 중복되지 않는다.
- [x] 사고 카드는 닫기나 Escape로 우회하지 않고 되감기로 돌아간다.
- [x] 되감기 횟수만 하나 늘고 조사·판단 시도·안전조치는 유지된다.
- [x] 되감기로 누락된 조치를 자동 완료하지 않으며 잘못된 잠금을 보완할 수 있다.
- [x] 움직임 줄이기에서도 고정 붉은 레이어, 암전, 카드, 되감기로 완주한다.
- [x] 위험 판정·유지 기록을 규칙 검사로, 두 사고 경로와 줄인 움직임을 실제 브라우저에서 검증한다.

## T6. 안전조치 후 이물질 제거와 결과 화면까지 완료하기

**만들 동작:** 안전조치가 미완료면 보완 안내를 받고, 모든 조치가 완료되면 안전한 이물질 제거와 결과 화면으로 한 판을 끝낸다.

**선행 작업:** T4. 잔류 에너지 안전조치와 차단 확인을 수행하기.

**선행 작업의 이유:** 정상 완료는 필수 조치와 확인의 실제 상태가 필요하다. 사고 연출 작업과는 별도로 정상 경로를 완성할 수 있다.

- [x] 차단·잠금이 유효하지만 표지·잔류 에너지 조치·확인이 빠졌을 때 미완료로 판정한다.
- [x] 표지 누락이나 확인 생략만으로 벨트가 반드시 움직인다고 표현하지 않는다.
- [x] 모든 필수 조치를 완료하고 확인이 유효할 때만 작업에 진입한다.
- [x] 성공은 안전한 이물질 제거 장면과 결과 화면으로 이어진다.
- [x] 성공 제목·교육 연결·마지막 문장은 원고를 따른다.
- [x] 완료한 조치, 판단 시도 횟수, 되감기 횟수를 실제 기록으로 표시한다.
- [x] 고정 설명을 제공하며 외부 AI 요청이나 API 키를 요구하지 않는다.
- [x] 유효한 진입 제출 한 번에 판단 시도는 한 번만 늘어난다.
- [x] 미완료 조합과 성공 조건을 규칙 검사로 확인한다.
- [x] 키보드만으로 공장 진입부터 결과까지 완료하고 화면 가림과 문구를 확인한다.

## T7. 공장 복귀와 재연습에서 한 판 상태를 올바르게 이어가기

**만들 동작:** 플레이어는 공장에 다녀와 기존 판을 이어가거나, 결과에서 다시 연습해 모든 기록과 현장 상태를 초기화한다. 사고를 겪은 판도 같은 규칙으로 동작한다.

**선행 작업:** T5. 불완전한 차단 상태로 진입해 사고와 되감기를 경험하기, T6. 안전조치 후 이물질 제거와 결과 화면까지 완료하기.

- [x] 공장 복귀 후 재진입 때 조사·안전조치·판단 시도·되감기·위치를 유지한다.
- [x] 진행 중인 판과 완료된 판을 구분해 공장 복귀 후 이전 완료 상태를 임의로 초기화하지 않는다.
- [x] 다시 연습은 조사·안전조치·기록·위치·카메라·입력·패널·연출 타이머를 새 판 상태로 되돌린다.
- [x] 연속 왕복과 재연습으로 이벤트·타이머·입력이 중복되지 않는다.
- [x] 사고 카드 도달, 되감기, 보완, 성공, 공장 복귀, 재진입, 다시 연습의 연결 흐름을 실제 브라우저에서 확인한다.
- [x] 규칙 검사로 되감기와 새 판의 차이를 확인한다.
- [x] 대표 화면 캡처와 재현 가능한 검증 기록을 남긴다.
- [x] 공용 코드·자산에 의도하지 않은 변경이 없음을 확인한다.

## 의존 관계 요약

T1 → T2 → T3 → T4 → T6
T3 → T5
T5와 T6 → T7

티켓마다 해당 동작의 검사를 포함한다. 별도의 이미지 제작 전용 티켓이나 검사 전용 티켓으로 사용자 행동을 쪼개지 않는다. 현재는 새 독립 구현이므로 광범위한 선행 재구성은 필요하지 않다.

## 완료 기록

판정 검사 6개와 실제 브라우저 흐름, 기준 및 명세 검토를 완료했다. 결과 설명 표기, 이미지 재시도, 키보드 포커스 문제를 수정했다. [검증 기록](../qa/검증.md)에 수행한 검사와 확인 한계를 남겼다.

작업 추적은 이 로컬 문서로 완료 처리한다. 공용 프로젝트 설정과 외부 이슈를 변경하지 않았다.
