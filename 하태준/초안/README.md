# 마지막 자물쇠: 6단계 행동 선택 체험

공장 전경에서 B/C 구역을 선택하면 조작반 근처에서 작업을 시작합니다. 작업반장이 “컨베이어 밑에 있는 이물질을 제거하세요.”라고 지시하고, “작업을 시작하기 전에 무엇을 하겠습니까?”라는 질문을 제시합니다.

진행 순서는 **설비 정지 → 오퍼레이터 전달 → MCC 개인 잠금 → 태그아웃 → 트라이아웃 → 이물질 제거**입니다. 단계마다 선택지는 정확히 네 개이며 정답은 하나입니다. 행동을 선택하면 현장 화면에서 그 행동과 상황 변화를 먼저 보여주고 설명 카드를 엽니다. 정답은 ‘다음 단계’로 진행하며, 오답은 선택별 위험을 확인한 뒤 같은 단계에서 다시 선택합니다. 사고가 발생하는 선택에만 사고 재현과 되감기를 적용합니다.

현장 절차를 검토하기 위한 교육 초안입니다. 실제 차단 대상, 잔류 에너지 처리, 작업 방법은 승인된 현장 절차를 따릅니다.

저장소 루트에서 실행합니다. 기본 체험은 npm 설치나 API 키가 필요하지 않습니다.

```powershell
python -m http.server 8770 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8770/하태준/초안/>을 엽니다. Phaser는 저장소의 `vendor/phaser.min.js`를 사용합니다. 현장 배경·작업자 자산은 초안 폴더에 있으며 공장 전경과 반장 역할 이미지는 기존 공용 이미지 경로에서 읽습니다.

- 공장 시설 이름표는 초안 배치입니다. B/C만 클릭하거나 키보드로 선택할 수 있습니다.
- 추천 다크 / 라이트 / 기존: 위치·단계·열린 창을 유지하며 화면 디자인을 비교합니다. 새로고침하면 추천 다크로 시작합니다.
- 좌우 방향키 또는 A / D: 이동
- 화면 화살표: 누르고 있는 동안 이동, 짧은 클릭 또는 Enter / Space로 한 걸음 이동
- E 또는 현장 행동 선택 버튼: 현재 단계의 위치에서 네 가지 행동 열기
- 선택 화면의 1~4: 해당 행동 선택
- ‘현장 보기’ 또는 선택 화면의 Escape: 현장으로 돌아가기
- 설명 카드: ‘다음 단계’ 또는 ‘다시 선택’으로 확인 후 진행
- 사고 카드: ‘되감기’로 선택 직전으로 복귀. 이전 단계의 안전조치와 기록 유지
- ‘공장 전경’: 위치·단계·안전조치·선택 결과·횟수를 유지하고, B/C 선택 시 이어가기
- ‘다시 연습’: 위치·단계·안전조치·입력·모달·타이머·횟수·설명 요청 초기화
- ‘움직임 줄이기’: 확대·흔들림·점멸 없이 행동 전후 상태와 결과 설명을 유지합니다. 연출 도중에도 바꿀 수 있습니다.
- 행동 장면: 선택창이 닫힌 뒤 근접 장면을 재생합니다. 이미지 실패 시 같은 선택을 횟수 증가 없이 다시 불러올 수 있습니다.
- 연출 중 공장 복귀 후 재입장: 대기 중인 행동을 처음부터 재생하며 기존 기록을 유지합니다.

선택적 AI 보충 설명 서버는 Node.js 22 이상에서 실행합니다.

```powershell
node 하태준/초안/server.mjs
```

<http://127.0.0.1:8780/하태준/초안/>에서 체험합니다. URL에 `?ai=on`을 붙이면 최종 결과의 보충 설명을 요청합니다. `OPENAI_API_KEY`는 서버 환경변수로만 설정합니다. `OPENAI_MODEL`과 `PORT`도 서버 환경변수로 설정할 수 있습니다. 키가 없거나 요청에 실패하면 고정 설명을 사용합니다. 단계 진행과 판정은 코드 규칙이 결정합니다.

규칙 및 서버 검사는 저장소 루트에서 실행합니다.

```powershell
node 하태준/초안/tests/scenario.test.mjs
node 하태준/초안/tests/server.test.mjs
node 하태준/초안/tests/actions.test.mjs
node --test 하태준/초안/tests/assets.test.mjs
node --test 하태준/초안/tests/motion.test.mjs
```

사용자의 명시적인 요청 없이 커밋하거나 푸시하지 않습니다.

수정 전후 비교는 <http://127.0.0.1:8770/하태준/초안/compare.html>에서 본인 잠금, 이물질 제거, 타인 잠금 오답을 선택해 재생할 수 있습니다. Node 서버 사용 시 포트는 8780입니다.

새 행동 이미지는 `assets/actions/v2/`의 24개 PNG입니다. 내장 이미지 생성 도구로 기준 사진을 편집해 제작했고, 실제 원본은 모두 1672×941입니다. 요청한 4K 해상도는 도구 출력에 반영되지 않았으며 확대 저장으로 대체하지 않았습니다. 잠금, 청소, 조작반과 무전의 전체 프롬프트는 각각 `isolator-prompts.md`, `access-prompts.md`, `control-radio-prompts.md`에 있습니다.

근접 장면은 설비·손·도구가 함께 들어간 사진을 행동 순서대로 보여줍니다. 사진 전체의 비율을 유지하고 브라우저 표시 크기를 원본 크기 이하로 제한합니다. 화면 픽셀 밀도(Device Pixel Ratio)가 높은 기기에서는 브라우저가 화면에 맞게 재표본화하며, 실제 4K 원본의 세부 표현을 제공하는 것은 아닙니다. 공장 진입 확대도 원본과 표시 크기에 맞춰 최대 1.2배로 제한합니다.

자막은 사진 밖에 두고 현재 행동과 전체 설명을 표시합니다. 일반 행동과 위험 발생 장면을 순서대로 재생하며 접촉 구간의 사진을 겹쳐 녹이는 효과는 쓰지 않습니다. 움직임 줄이기에서도 전후 상태와 사고 설명을 확인할 수 있습니다. 음성·배경음은 포함하지 않습니다.
