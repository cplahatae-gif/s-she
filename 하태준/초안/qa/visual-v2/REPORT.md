# 근접 장면 수정 검증

2026-10-09. 작업 범위는 하태준/초안이다. 시나리오와 서버 판정, 6단계의 24개 선택은 유지했다.

## 구현

- 새 사진 24장: 잠금 11장, 청소 7장, 조작반 및 무전 6장.
- 사진 안에서 손과 도구가 실제 물체에 접촉하도록 제작하고 도형 손잡이·고리·표시등·이물질 합성을 제거.
- 같은 기준 사진의 편집으로 전후 구도 유지, 선택별 시간표로 순서 재생.
- 사진 전체 비율 유지, 과도한 CSS 확대와 잘림 제한. 큰 화면에는 여백이 생길 수 있음.
- 엄격한 물리 픽셀 제한은 고밀도 화면에서 장면을 너무 작게 만들어 브라우저 표시 크기를 기준으로 제한하도록 조정.
- 자막은 사진 밖, 단계명과 전체 무전·행동 설명 유지. 모바일은 사진과 자막을 붙여 배치.
- 공장 진입의 2.5배 확대를 원본과 표시 크기에 맞는 최대 1.2배 확대 및 전환으로 변경. 로딩 중 현장 배경 표시.
- 실제 잠금 지점과 문고리, 본인과 타인 잠금, 대상 A와 B/C, 본인 표지와 타인 이름 및 훼손 표지를 구분.
- 위험은 사고 단계에서만 표시해 준비 상태로 되돌아오는 중복 연출 방지.
- compare.html에서 3개 대표 장면 수정 전후 비교 및 실제 재생.

## 검사

- 시나리오 검사 15개, 서버 검사 23개, 이동 검사 6개 통과.
- 사진 파일 검사: 모든 일반·사고 장면의 파일 존재, PNG, 실제 크기, 비율 확인.
- 행동 재생 검사: 선택 24개 순서, 선택 이미지 사전 해독, 상태 반영 시점, 사고 4개, 이미지 및 해독 실패, 취소 경합, 재시도, 종료 확인.
- 오답에 본인 표지 접촉 사진이 끼지 않는지, 일반 재생에 사고 위험 사진이 먼저 나오지 않는지 추가 검증.

## 실제 브라우저

- 1920×1080에서 24개 선택 모두 실행. 결과 선택 24회, 되감기 4회.
- 각 선택에서 새 v2 사진 사용, 합성 도형 없음, 당시 화면 경계와 크기 제한 확인.
- 전체 선택 실행 이후의 최종 배치 조정은 모바일 390×844(픽셀 밀도 3), 데스크톱 2560×1440(픽셀 밀도 2)에서 재검증.
- 최종 배치에서 사진과 자막이 화면을 넘지 않고 행동 장면이 헤더를 가리지 않음. 연출 중 움직임 줄이기 변경 후 결과 도달. 페이지 예외 없음.
- control-stop 이미지 요청을 의도적으로 실패시켜 재시도 창 확인. Escape로 결과를 건너뛰지 못함.
- 재시도 중 공장 복귀와 재입장 후 같은 선택 1회 유지, 이전 장면 제거 및 다음 단계 진행 확인.
- 설명창에서 디자인 3개 전환 후 선택 횟수 유지.
- 비교 페이지의 뒤로가기 캐시 보존 pagehide 이벤트를 브라우저에서 모의 발생시킨 뒤 재생 정상 확인. 실제 캐시 복원 여부를 측정한 것은 아님.

수치는 browser-results.json과 stage-1.json부터 stage-6.json에 있다. 반복 검사 소스는 browser-checks.mjs다. 도구 실행 환경이 직접 import를 지원하지 않아 소스와 시나리오 데이터를 읽어 함수 본문으로 전달했다. 전체 선택 검증 후 배치만 조정했으므로 최종 배치에서 전체 24개를 다시 순회하지는 않았다.

각 선택 ID PNG와 result-24.png는 해당 실행의 캡처다. 일부 짧은 장면은 캡처 시점에 결과 카드나 최종 사진으로 넘어가 있다. compare-lock/access/other.png, mobile.png, desktop-2x.png는 별도 확인 캡처다.

## 한계

원본은 모두 1672×941이며 실제 4K가 아니다. 고밀도 화면에서는 브라우저 재표본화가 발생한다. 연속 동영상 대신 몇 장의 사진을 순서대로 재생하며 생성 편집 특성상 미세 질감은 바뀔 수 있다. 사진은 현장 장치 구조와 안전 절차의 실증 자료가 아니다. 실제 모바일 하드웨어, Safari와 화면 읽기 프로그램, 외부 AI 실호출은 검사하지 않았다. 커밋·푸시는 하지 않았다.
